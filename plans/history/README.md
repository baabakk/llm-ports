# Release history recovered from outside the repository

**Recovered 2026-09-11 from `E:/tmp/llm-ports-extract-scratch`.** Every file here existed in exactly one place, a temporary folder, and nowhere in this repository. Thirteen documents, 1303 lines.

They are filed unedited. Nothing below this README has been reformatted, retitled or reconciled against what later shipped, because the value of a primary source is that it says what was said at the time.

## Why this folder exists, and what it proves

The release journal records that four consecutive themed releases were announced and then displaced, and that nobody noticed for four releases. The diagnosis written at the time was that **scope living outside the repository is scope nobody reconciles**, and the remedy adopted was that every release gets a plan document in `plans/` before it ships.

This folder is that diagnosis confirmed harder than intended. The alpha.29, alpha.30 and alpha.31 item lists were reconstructed on 2026-09-05 from a planning conversation, because they were believed to survive only inside GitHub discussions. **Local copies of those discussion bodies were on disk the whole time**, in a folder whose name marks it as disposable.

Two consequences worth stating plainly:

- A sweep that deleted temporary folders without reading them would have destroyed the primary sources for three release themes.
- The reconstructions in `plans/alpha.29-capability-factory-ergonomics.md`, `plans/alpha.30-persistent-backends-and-caching.md` and `plans/alpha.31-local-runtime-and-orchestration.md` can now be checked against the originals rather than trusted.

## The rule this folder exists to enforce

A document that exists in one place, and that place is a temporary folder, is not stored. It is queued for deletion by whoever next tidies up.

Before deleting any working directory, list the documents in it and check each against this repository. The alpha.26 messages-unification plan, 1131 lines for a shipped breaking release, was recovered from the same temporary folder one day before these were.
